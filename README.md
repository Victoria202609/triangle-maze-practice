# 三角迷阵 · 闯关练习

一个纯静态、可离线运行的三角迷阵模拟练习程序。行数可选 5–25 行，共 5 关，每关可选 5 或 10 题（整套 25 或 50 题），每关独立限时 5 分钟。开始前选择的行数和题量适用于全部 5 关。

## 开始练习

直接双击 `index.html`，使用浏览器打开即可。程序没有第三方依赖，也不需要安装或联网。

## 游戏规则

1. 路径从三角形顶点开始。
2. 每进入下一行，只能选择当前节点左下或右下的相邻节点。
3. 发光点计 1 分，普通点计 0 分。
4. 路径到达最底行后提交答案。
5. 每道随机题均经过校验，恰好只有一条最高分路径。
6. 每题提交后显示玩家路径与动态规划计算出的唯一最优路径。
7. 每关共用 5 分钟，同一关内复盘时继续计时；完成本关或时间到后暂停，点击下一关才重新计时 5 分钟。
8. 可随时点击“退出练习并查看成绩”。已提交题保留在本次成绩中，退出时未提交的当前题不计分。退出后可返回设置或按原设置重新练习，不支持续接已退出的练习。
9. 本关超时时，当前题若已走到最底行则计入捕获分数，否则计 0 分；尚未进入的题显示为“未作答”，仍可进入下一关。
10. 捕获率只统计已提交、跳过或超时结算的题目。完成全部题目时才更新本机最佳记录，记录按行数和每关题量区分。

## 已实现功能

- 行数可选 5–25 行（底行节点数与行数相同），默认 14 行
- 共 5 关，每关可选 5 或 10 道随机题，默认 5 题
- 动态规划统计最优路径数量，排除所有并列最优题目
- 5 个难度阶段：观察比较、识别诱饵、多步判断、深层比较、综合挑战
- 不再使用“将整条答案路线点亮”的兜底。每题最优路径连续亮点不超过 3 个，至少四分之一的节点（且不少于 2 个）不发光
- 每题至少有一个需要放弃眼前亮点的岔路；即使平分时总是幸运地选对，单纯逐步追亮点也无法取得最优分
- 使用已校验题库、随机干扰点变化和左右镜像生成题目；变化后重新检查唯一解及难度，不合格时使用原合格题
- 同一行数下，按向后比较的层数、诱饵岔路数、接近最优的路线数量等指标递增排序；5 行可用结构较少，允许相邻题难度相同，也可能出现左右镜像题
- 每关 5 分钟倒计时和最后 60 秒提醒，关卡之间可休息
- 可选节点提示、撤销一步、重置路径、跳过题目
- 玩家路线与最优路线可视化对比
- 中途退出、已作答捕获率、分关逐题成绩与本机最佳记录
- 鼠标和键盘操作
- 响应式页面，可在电脑或手机浏览器中使用；大迷阵可在棋盘内横向滚动

## 测试

算法单元测试：

```bash
node --test tests/solver.test.js
```

题目质量与难度梯度测试（包含全部题库、5–25 行及两种题量的随机练习）：

```bash
node --test tests/generator.test.js
```

确定性重建题库（通常需要一到数分钟，题库文件已随程序提供，日常使用无需运行）：

```bash
node scripts/build-question-bank.js
```

浏览器交互测试（需要设置 `CHROME_PATH`）：

```bash
node scripts/smoke-test.js
```
